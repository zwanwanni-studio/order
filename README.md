# zwanwanni.studio - แบบฟอร์มสั่งซื้อฟอนต์

หน้าสั่งซื้อฟอนต์ Flower and Love และ Caveman

## โครงสร้างไฟล์
- `index.html` หน้าแบบฟอร์มหลัก
- `assets/` รูปโลโก้ รูปตัวอย่าง ตารางตัวอักษร QR PromptPay และไฟล์ฟอนต์ chantaidin

## วิธีเปิดหน้าเว็บด้วย GitHub Pages
1. สร้าง repository ใหม่บน GitHub (เช่น `zwanwanni-order`)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repository (รวม `index.html` และโฟลเดอร์ `assets/`)
3. ไปที่ Settings > Pages แล้วเลือก Source เป็น `Deploy from a branch`, Branch `main`, โฟลเดอร์ `/ (root)`
4. รอประมาณ 1-2 นาที ลิงก์จะเป็น `https://<username>.github.io/zwanwanni-order/`
